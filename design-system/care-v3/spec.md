# 护理台 v3 设计 spec（三个方向共用输入）

只写"要说什么"，不写"长什么样"。长什么样是方向卡的事。

## 项目
回南天 Cyber Damp：Windows 桌面上的真实图标会因为天气受潮、发霉、焦化、长蘑菇。护理台是玩家处理它们的游戏窗口。胶囊、托盘、新手引导后续沿用选定方向的视觉语言。

## 用户的原话（2026-10-26）
- "UI/UX 设计过于低端和丑陋（需要完全推翻重构）"
- "当前无动效，无设计感，无玩法，无交互体验"
- "我们要的不是一个旧作同款布局但长得更好看的交互界面，而是一个真正布局有意思，玩法好看，交互丝滑的游戏窗口"
- 风格语境：B（像《动物森友会》那样的圆润卡通游戏 UI）
- 交互动画放在护理台

## 受众与场景
桌面用户每天打开一两次，每次 1–5 分钟。打开窗口的那一刻，要立刻看到"我的桌面今天怎么了"；动手处理时要有手感；处理完要有回报。不是任务清单，也不是打卡。

## 核心信息（按优先级）
1. 哪些桌面对象出事了、出了什么事（受潮 / 霉变 / 焦化 / 长菇），严重到什么程度
2. 把一个对象拿出来护理：选工具、擦、看着污渍消失、最后一点自动收尾
3. 成熟菇用剪刀剪下：得菇币，有时掉孢子
4. 今天的天气，以及它为什么让桌面变成这样（湿度、降雨、回南天警报）
5. 次要入口：图鉴（13 款菇）、小铺、墙面、设置

## 情感基调
潮湿但不脏，治愈，带点幽默。是"照料"，不是"清洁工作"。

## 输出格式与尺寸（三版统一）
- 单文件 HTML（共用 `assets/engine.js` 与 `assets/objects.js`），窗口 960×640（护理台实际窗口尺寸量级），截图 960×640
- 必须真的能玩：选对象、拿工具擦（擦除用真实材质图）、≥90% 自动收尾、剪刀采菇、完成反馈

## 已知约束
- 原生图标是主角，必须可辨认；不能把图标画成别的东西
- 桌面上的真实图标不移动、不改名；界面里的"挂起来、搬过来"只是窗口内表现
- 可读性：正文 ≥14px，标签 ≥12px，正文对比度 ≥4.5:1
- 不用 emoji 当图标，不用占位图；美术资产还在制作中，可用程序化绘制（SVG/canvas）来补位，但要标注"程序化占位"

## 素材（T0 档，三版共用）
- 8 个 Windows 自带对象的真实 Shell 图标，经产品 `state-icon.ts` 生成干净图、损伤图、桌面长菇图（`assets/objects/`）
- 13 款菇素材：`src/renderer/public/assets/care/species/`
- 工具素材（海绵、剪刀、刷子等）：`src/renderer/public/assets/care/` 与 `previews/visual-assets-2026-10-24/repair-tools-v1/png/`
