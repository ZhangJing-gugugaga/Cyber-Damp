# 下一版护理与桌面融合验收

状态：全部待实施、待验证；不是历史测试通过项。依据：[2026-10-19 设计](superpowers/specs/2026-10-19-care-and-desktop-design.md)。未解决决策对应项目待口径确认后补齐边界测试。

- [ ] 启动前后原生图标大小、位置与数量一致，支持不同 DPI、多显示器及小/中/大图标；高分辨率资源不导致显示放大。
- [ ] 初次读取修改时间，快进终点有差异；开场 3–5 秒，重启再次播放，播放前有提示。
- [ ] 正常桌面尺寸能辨识湿润→黑点→斑片→幼芽→伸柄展伞；根部稳定，生长轻微自然摇摆。
- [ ] 严重霉变遮挡不超过 55%，原图和名称仍可认，邻近图标不受遮挡干扰。
- [ ] 晾晒/烘干降低湿度但不瞬间清除黑点；批量洗文件机与耗材作用符合最终护理定义。
- [ ] 清洁度 34.99/35/50/50.01/100% 的收益档位分别为 0/1/1/1.5/10；满值判据与结算时间规则另按 D02/D05 补测。
- [ ] 低于 15% 且超过三天只按最终 D03 规则损坏最腐烂的一个对象；15% 边界、恰好三天、退出与休眠均有测试。
- [ ] 游戏内损坏不会更改真实文件；正常打开仍可用；护理不恢复；用户退出后重命名或修改再启动可按换新规则恢复。
- [ ] 重启、反复领取、跨日、系统时钟变化不会重复发币或偷计离线惩罚；旧文件护理成果按 D01 保留或重算。
- [ ] 干燥蘑菇降价但仍可采；胆小菇与原核爆菇仅以 PVZ 铲子采摘；生气动画根部不动、上部逐渐增强，无爆炸。
- [ ] 蜗牛低频出现，不清洁、不增币、不截获用户操作。
- [ ] 管理窗口承载商店、设置和管理弹窗；关闭窗口、退出游戏的结果明确；不散落旧版面板。
- [ ] 快捷键可修改，冲突有提示，保留可用入口；不改变已有其他软件快捷键。
- [ ] 最终交付运行原生桌面视觉与交互验收；不能以脚本断言代替肉眼和鼠标实测。当前本轮未运行任何产品测试。
