# 当前原生产品验收

行为目标以 [PRODUCT.md](PRODUCT.md) 和用户最新决定为准。矩阵中 R0–R8 引用该规格；状态与待修项见 [CURRENT-STATUS.md](CURRENT-STATUS.md)。本文列验收要求，未列为本轮已通过。

有效修订：未选城用明确标记的默认长沙，离线内置快照须标注；Win+D 允许隐藏并由托盘唤回；旧覆盖层/物理绳索不进入验收。A10/A18/A22 的无缓存断网预期按此修订，不能再要求默认策略永远停在待联网。默认数据仍不能冒充实况。

测试先读取[项目 UAT 技能](../.agents/skills/cyber-damp-uat/SKILL.md)，用隔离存档和限定探针；真实桌面输入、图标引用、安装包、性能与用户感官分别验证。源码/HTML预览/规则测试不能相互冒充。缺设备或未观察项记 NOT TESTED。

提交与推送纪律：修改后执行适合范围的检查；推送后用远端查询核对提交，不强推、不自动发布安装包。历史资料移除必须先确认相应存档提交在远端。
