# 2026-10-22 当前轮补充

历史性能认可不代表当前通过。先检查：双击启动程序后不弹播放确认页，自动完成接管和回放；分别记录资源准备、接管及回放耗时。文件名始终白色、可读，不随霉变、焦化、拧干或摆动改变。

输入检查：默认浏览支持选中、打开与替身拖动；选中剪刀/喷雾/吹风等后不触发图标打开或选择，非采摘工具不自动采菇；有效目标与工具状态可辨认；Esc取消按住/拖动并回到浏览，切应用或暂停不会留下手势。必须原生输入验证桌面子窗失焦时的Esc路径，不能只靠DOM键盘测试。

运行流畅度按实际版本、屏幕缩放、对象数和后台负载记录帧间隔与长帧；编译/压缩同时运行的采样单列，不能挑选最好的一次作为全机达标。瞬移后点击、Ctrl多选、正常/强制退出恢复继续按下方标准验证。
