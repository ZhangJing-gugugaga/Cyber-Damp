# ADR-002: 使用 Pixi.js 8.21.0 作为渲染层

## Status: Accepted (2026-10-16)

## Background

写实拟物视觉（水珠、霉斑、焦化、挂雾）依赖自定义 Shader；场景需要大量 2D 精灵、粒子与图层合成。候选：Pixi.js 8.21、Phaser 3、裸 WebGL2、Three.js。

## Decision

选定 Pixi.js 8.21.0（2026-09-17 发布，v8 为当前唯一主线，7.x 停止演进）。

核验依据（2026-10-16，官方文档 pixijs.com/8.x/guides/components/filters）：
- v8 自定义滤镜标准形态：`new Filter({ glProgram: new GlProgram({ vertex, fragment }), resources: { <group>: { <uniform>: { value, type } } } })`，uniform 更新走 `filter.resources.<group>.uniforms.<name>`。
- v8 初始化为异步：`const app = new Application(); await app.init({...})`；挂载点为 `app.canvas`。
- 渲染偏好默认顺序 webgl → webgpu → canvas（8.1 起），显式 `preference: 'webgl'` 即可锁定 WebGL。
- v8 内置 AlphaFilter / BlurFilter / ColorMatrixFilter / DisplacementFilter / NoiseFilter 与 advanced-blend-modes 扩展。

否决理由：
- Phaser 3：物理绑定 Arcade（无法满足绳索刚体需求），自定义 Shader 需走 Pipe 体系，自由度与学习成本双输。
- 裸 WebGL2：MVP 周期不允许自建场景图/合批/文本渲染。
- Three.js：2D 挂件场景使用 3D 引擎属架构倒挂。

## Consequences

正面：Shader 一等公民；v8 自动合批支撑同屏数百精灵；MIT 协议；ESM-first 与 Vite 8 契合。
负面：v7→v8 为破坏性迁移（异步 init、Filter 构造变化、Graphics build-then-fill、禁 beginFill），团队必须按 v8 文档书写，禁止凭 v7 记忆写码（R1 缓解条款）；v8 包体较 v7 明显增大（渲染层性能换体积，可接受）。
