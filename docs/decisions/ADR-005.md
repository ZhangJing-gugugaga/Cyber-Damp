# ADR-005: 锁定 Lucide 1.58.0 为全项目唯一 SVG 图标库

## Status: Accepted (2026-10-16)

## Background

团队 P0 规则：禁止 emoji 作为功能图标；必须锁定一套 SVG 图标库并由架构师选型，全项目统一不混用。本项目有两处图标消费面：DOM 覆盖层 UI（商店侧栏/气象牌/工具箱/Demo 控制台）与 Pixi 画布内少量工具/菌种图示。

## Decision

锁定 lucide@1.58.0（npm dist-tags latest，2026-10-16 发布；零依赖，ISC 协议）。

选型理由：
- 原生 DOM 直接可用：`import { createIcons, icons } from 'lucide'` + `createIcons({ icons })` 替换 `[data-lucide]` 元素，不绑任何 UI 框架（本项目 DOM 层不用框架）。
- 图标以 `[tag, attrs, children]` node 导出，可序列化为 SVG 字符串，再经 Image → Canvas → Pixi Texture 贴入画布，一套数据两处消费。
- 1500+ 图标覆盖天气/工具/商店/蘑菇语义；ISC 协议无授权风险；零运行时依赖。

分工纪律：
- DOM UI 一律 Lucide；Pixi 画布内的游戏实体（文件替身/菌盖/绳）为程序化绘制 Graphics，不使用图标库贴图，保持拟物手绘感。
- `renderer/types/lucide.d.ts` 提供 ambient 声明（该包无内置类型）。
- 禁止 emoji 充当功能图标；禁止引入第二套图标库。

## Consequences

正面：风格统一、tree-shake 友好、两处消费面同源。
负面：需自带 10 行 ambient 类型声明；canvas 贴图路径需自建 icon→Texture 工具（约 30 行，见 renderer/ui/icons.ts 规格）。
