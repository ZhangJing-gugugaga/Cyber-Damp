# ADR-007: 本地种子模拟天气源（真实 API 后置）

## Status: Accepted (2026-10-16)

## Background

PRD 模块一要求"零配置天气服务、无需 API Key、全球城市切换、每日限迁 1 次"，且项目总监口径明确 MVP 零后端零数据库零认证。引入真实天气聚合 API 会带来：API Key 归属与分发、网络失败降级、速率限制、地域访问差异（海外源在国内不稳定）等一系列 MVP 无关成本。

## Decision

MVP 天气 = 本地确定性模拟器（world/weather-simulator.ts）：
- 城市表内置基础温湿度 profile（广州/敦煌/吐鲁番/阿塔卡马/伦敦/东京等）。
- 当日天气由 `hash(city) + dayIndex` 种子确定性产出 {tempC, humidity, condition}，同日同城结果稳定、可回放、可测试。
- 游戏规则不变：雨天/湿度 >80% → 受潮与蘑菇生长翻倍；晴天 → 挂绳文件自然风干；干旱地区长期不保湿 → 脱水木乃伊化。
- 迁徙限制 1 次/日，持久化在 save.weather.migratedOn。

接口先行：`WeatherPort { today(city): WeatherReading }`，后置实现 `HttpWeatherPort`（真实 API）时仅新增实现类，领域层零改动。

## Consequences

正面：零配置、零 Key、零网络依赖、确定性可测；比赛现场断网可演示。
负面：天气非真实（玩家无法按真实预报制定策略）；真实 API 接入需后置并处理降级。该代价在"虚拟数据源"总口径下可接受。
