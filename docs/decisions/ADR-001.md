# ADR-001: 使用 Electron 44.8.0 作为桌面外壳

## Status: Accepted (2026-10-16)

## Background

《回南天》需要 Windows 透明、无边框、置顶、支持点击穿透的桌面挂件形态，且渲染侧依赖 WebGL2 + 自定义 GLSL Shader 与高密度 2D 场景图。候选方案：Electron 44.8、Tauri 2.x、Unity URP 2D（PRD 方案 A）、WPF/.NET 原生。

## Decision

选定 Electron 44.8.0（当前最新稳定线：Chromium 152.0.7977.54 / Node v24.18.1 / V8 15.2）。

核验依据（2026-10-16）：
- npm registry dist-tags：electron latest = 44.8.0；45 线仅 alpha/beta。
- 官方文档确认 `win.setIgnoreMouseEvents(ignore, { forward: true })`（macOS/Windows）与官方 click-through 教程 IPC 模式存在且当前有效。
- 官方文档确认透明窗口选项族：transparent / frame:false / hasShadow:false / backgroundColor '#00000000' / setAlwaysOnTop(level)。

否决理由：
- Tauri 2.x：Windows WebView2 版本碎片化导致透明穿透行为需逐用户机器验证；Rust 工具链学习成本与 MVP 周期冲突；省下的包体对比赛演示无决策价值。
- Unity URP 2D：Shader Graph 迭代慢于手写 GLSL；包体与团队经验双输；为 2D 挂件引入完整游戏引擎属过度设计。
- WPF/.NET：无 WebGL Shader 管线，水珠/霉斑写实效果无法落地。

## Consequences

正面：Web 技术栈直通渲染与 UI；透明穿透 API 文档级完备；Chromium 152 保证现代 WebGL2/GLSL ES 3.0 能力；Node 24 侧可直接做文件与系统监控。
负面：包体 ~90MB 起；透明全屏 WebGL 在部分 Windows 机器有 alpha 合成开销（以 R3 缓解条款控制）；需自行处理单实例、退出保存、SmartScreen 未签名提示。
