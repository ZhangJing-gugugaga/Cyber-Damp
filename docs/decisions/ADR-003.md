# ADR-003: 使用 Matter.js 0.20.0 作为物理层

## Status: Accepted (2026-10-16)

## Background

核心玩法"悬链线晾衣绳 + 文件配重 + 滑落挤团 + 摔落弹跳"同时需要约束链（绳索）与刚体碰撞。候选：Matter.js 0.20、Planck.js（Box2D 移植）、自建 Verlet 绳 + 简易碰撞。

## Decision

选定 matter-js 0.20.0 + @types/matter-js 0.20.2。

核验依据（2026-10-16，npm dist-tags + brm.io/matter-js/docs）：
- matter-js latest = 0.20.0（2024-06-23 后无新版，API 稳定）；@types/matter-js latest = 0.20.2（含 ts5.9 tag）。
- `Composites.chain(composite, xOffsetA, yOffsetA, xOffsetB, yOffsetB, options)` 存在，官方 bridge/cloth 示例即约束链绳索范式。
- `Constraint.create({ bodyA, pointB, ... })` 在 bodyB 缺省时锚定世界坐标点，满足"两端吸盘"需求。
- `Body.setMass` / `Engine.update(engine, delta)` / `Query.point` 均存在。

否决理由：
- Planck.js：解算质量更高但社区/文档量小一档，API 面更大，MVP 不需要 Box2D 级精度。
- 自建 Verlet 绳：绳索简单但无刚体碰撞，"挤作一团/交叉感染/摔落弹跳"玩法无法实现。

## Consequences

正面：绳索与刚体一站式解决；文档与示例极丰富；序列化能力为存档重建提供参照。
负面：迭代式约束解算在大质量比下会拉伸抖动（R4：质量比 ≤ 35:1、constraintIterations 4、positionIterations 8、固定步长 16.666ms 累加器）；CJS 包需统一 `import Matter from 'matter-js'` 后解构的导入形态。
