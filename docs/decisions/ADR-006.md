# ADR-006: Vite 8.3.4 + TypeScript 5.9.3 + electron-builder 26.15.3（portable）

## Status: Accepted (2026-10-16)

## Background

需要渲染层构建工具、类型系统与 Windows 分发产物。候选构建：Vite 8.3.4 / webpack 5 / esbuild 裸用；类型：TS 5.9.3 / TS 7.0.2（原生 Go 编译器）；打包：electron-builder 26.15.3 / Electron Forge / 手工 zip。

## Decision

- 构建：Vite 8.3.4（npm latest）。渲染层为零框架单页，Vite dev server + 构建足够；配置保持最小化。
- 类型：TypeScript 5.9.3（5.x 收官版）。TS 7.0.2（2026-07 发布，原生编译器）暂缓——发布仅 3 个月，编辑器/插件生态在迁移期，MVP 不抢鲜。
- 打包：electron-builder 26.15.3（npm latest tag）。`build.win.target: "portable"` 产出免安装单文件 exe，契合比赛演示分发；portable 不生成 app-update.yml（MVP 无自动更新，可接受）。v27 为 ESM 化 alpha 线，不追。
- 主进程/preload/shared 用 tsc 独立编译（module: commonjs），渲染层走 Vite（ESNext），双 tsconfig 分离。

核验依据（2026-10-16）：npm dist-tags；electron-builder 官方 win 文档确认 `target: "portable"` 为合法值且语义为免安装便携应用；Vite 官方迁移指南确认 Vite 8 工具链为 Rolldown + Oxc。

已知坑（写入 Spec 硬约束）：
- Vite 8 中 `build.rollupOptions` → `build.rolldownOptions`；`esbuild` 配置 → `oxc`；`minify: 'esbuild'` 已废弃；不支持 ES5 降级。本项目 vite.config.ts 不触及以上面，规避为主。
- electron-builder 若 latest 线出问题，回退线为 `npm i -D electron-builder@v26`（26.17.0）。

## Consequences

正面：dev/构建/打包三件套全部文档明确；portable 单文件贴合演示场景；TS 5.9 认知度最高，AI 辅助产出幻觉率最低。
负面：Vite 8 工具链较新（Rolldown/Oxc），冷门插件兼容性未经本项目验证——以"最小配置"约束自身；未签名 portable 会触发 SmartScreen 提示（README 引导用户）。
