# 材质与自然菌种补齐

本轮直接执行用户已给定的 UAT 设计：持续热风超过5秒才开始焦化，先白烟后焦褐/黑边；干旱或挂绳过晒后缩水20%、纸纹卷边、点击干叶脆响；潮湿文字保持白色可读并出现轻微洇水重影；旧“新建文件夹”自然出现胆小菇。

- 热风累计以同一目标连续按住为准，松开/失焦/切目标即清空持续时间，已产生的焦痕保留。气象热源采用相同演化函数。
- 脱水度由领域运行态维护，渲染和点击音效读取同一数值。旧存档缺失时为0；新增值可选、范围0至1。
- 文件名只在显示层变形。焦化随机选择稳定的1–2个字元绘制黑色炭块，保留扩展名与真实打开路径。使用 Canvas 文本绘制，避免把用户文件名解释为 HTML。
- 潮湿文字以低透明度模糊副本产生洇水，原文字始终完全不透明；开局0–1秒无洇水。
- 新建文件夹规则仅作用于真实目录的 Windows 默认中英文名称及编号变体，种子和后续自然萌生共用同一选择函数。

验证：先保留旧实现的失败回归，再完成类型检查/领域测试/生产构建；准备实际桌面临时文件，经 Windows-MCP 原生鼠标操作验证视觉与行为。未经原生观察或听取的项目保持未验收。下一批继续麦克风、染色、特殊蘑菇闭环和大文件夹重量。
