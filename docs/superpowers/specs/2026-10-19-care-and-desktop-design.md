# 回南天：桌面发霉体验与辅助交互设计

日期：2026-10-19。状态：用户决策已记录；计算细则待讨论；开发保持暂停。本文件描述下一版目标，不代表当前代码或安装包已实现。

## 文档优先级与范围

本轮用户决策优先于旧 PRD、SPEC、DESIGN、修复计划及原始 UAT 中的冲突要求；未涉及的要求继续保留。原始 UAT 与历史测试记录保留为历史证据，不能作为新规则已通过的证明。美术执行见 [ART-DIRECTION](../../../design-system/ART-DIRECTION.md)，新增验收见 [护理与桌面验收](../../CARE-DESKTOP-UAT.md)。

用户最新澄清：项目宗旨是丰富用户桌面，“没什么用但是很好玩”。把发霉这一件事做好就足够了。“玩”“养”和照料经营都不是产品目标；此前将 A 解读成“照料为主、允许养菇”的主线过度强调了游戏逻辑，以本段修正为准。

核心交付是桌面自然受潮、出现黑点、逐渐霉变与长出蘑菇的观感，以及顺手、轻量、有趣的交互。用户不操作时也应获得完整的桌面体验。金币、护理、商店是辅助内容，不能要求用户学习复杂规则、持续照料或追求收益最优。不得增加每日任务、强制打卡或经营层。

下方此前确认的具体规则保留作为辅助功能记录，本次不擅自删除。它们的数值细则不阻塞发霉样片与桌面融合设计；若与轻量体验冲突，后续优先简化，不以完善经济闭环为开发目标。

## 已确认的规则

### 清洁度、金币与游戏内损坏

以下 C 表示用于结算的清洁度；它如何由各文件汇总仍待 D02 决定。

| 清洁度 C | 每日金币倍率 |
| --- | --- |
| C < 35% | 0 |
| 35% ≤ C ≤ 50% | 1 |
| 50% < C < 100% | 1.5 |
| C = 100% | 10 |

持续低于 15% 超过三十天，将腐烂最重的一个文件标记为游戏内“损坏”：持续腐烂、不产金币、护理无法恢复。退出期间不计清洁度惩罚时间。计时累计、重新进入低清洁区间与触发后是否重复，见 D03，不能默认扩展成连续批量损坏。

损坏只存在于游戏存档和画面中，真实文件内容、名称、权限与打开能力不受影响。用户自行退出游戏、重命名或者修改真实文件，再启动重新读取，可模拟换新衣物。游戏不能代替用户执行这些文件操作。重命名不一定改变修改时间，恢复识别不能只比较 mtime；识别细则随 D01 落定。

降低基础每日金币和蘑菇售价以控制通胀；用户指定倍率保持不变。尚未批准基础收入、售价、护理成本及设备价格，不写入臆定的正式数值。

### 衣物护理与商店

晾晒/干燥降低含水量、阻止继续恶化，不能直接洗掉已有黑点。商城引入洗文件机、烘干机、消毒剂、清洁剂，支持批量快速护理。具体作用建议：清洁剂去渍，消毒剂抑制再生，洗文件机批量清洗，烘干机批量干燥；此作用分工、耗材配方、用时和成本尚未批准。

现有双击即完全清洁的行为需要重新定义，不能绕过护理或恢复永久损坏。双击打开真实文件的能力必须保留。是否附带轻微护理列入 D04。

### 蘑菇与场景生物

- 湿度充足时蘑菇才有最佳品相和售价；湿度不足会降价。始终可采摘，不因品相差而禁采。
- 胆小菇与原核爆菇必须购买“PVZ铲子”才能采摘。始终可采摘指生长/品相不应制造额外成熟门槛，工具要求仍有效；萌芽阶段是否已有可售价值见 D05。
- 原核爆菇取消爆炸。用户靠近时生气呼吸：根部固定，越向顶部形变幅度越大，连续数次收缩舒张，参考 PVZ 火爆辣椒的动作感觉。禁止整张图片等比放大缩小代替生长或呼吸。
- 蜗牛为低频场景彩蛋，与雾气、风一样提供氛围；无清洁、收益或操作干扰功能。减少出现次数，具体频率通过后续样片判断。

### 启动与原生桌面

- 首次启动读取各文件上一次修改时间，估算霉变终点；一起以快进动画呈现受潮、黑点、严重霉变及蘑菇生长，生长伴随轻微自然摇摆。每个文件只演到自己的终点，不强制全部长蘑菇。
- 开场总时长 3–5 秒，每次重启重播，播放前必须有提示或弹窗。是否需确认、是否可跳过是 D06，不能把每次重播擅自改成仅首次播放。
- 退出后停止清洁度计时；重启重新读取并计算各文件霉变与清洁度。如何合并护理存档见 D01；不允许未经讨论把“重新计算”实现为无条件抹掉护理成果。
- 严重霉变最多遮住图标 55%，原图保持可辨认。建议验收以原图有效不透明像素为基准，统计霉层与腐烂层联合遮挡；蘑菇不得借根部在图标外绕过可辨认性要求。具体遮挡测量方式在实现方案确认。
- 按用户启动前的原生图标显示大小与坐标绘制，保留原有排版。高清素材分辨率不等于屏幕显示尺寸。禁止固定大图标、自定义网格重排，或为顶部控件挪动全部图标。
- 独立普通窗口收纳商城、设置及管理弹窗，桌面保留直接玩耍所需的场景交互。窗口关闭与整个游戏退出必须区分；具体入口流程见 D06。
- 提供用户可编辑快捷键。参考用户本地 Snipaste 的快捷唤起方式，优先不常用按键或简短组合。不能承诺任何系统级组合永不冲突；注册冲突需提示并允许重设，保留窗口/托盘入口。默认按键和触发动作尚未锁定。

## 美术方向已定

**与原生图标融合的平滑漫画风桌面微生态。** 真实性体现在附着位置、渐进过程、接触阴影和生长动作。柔和体积、干净轮廓、克制纹理，不追求微距霉菌写实。详细制作标准见美术文档。

## 辅助功能待决项（不作为发霉视觉工作的前置门槛）

| ID | 问题与风险 | 建议，尚非批准规则 |
| --- | --- | --- |
| D01 | 重启重算可能清除护理成果；重命名旧文件但 mtime 不变又立即重度霉变 | mtime 建立初始基线，叠加已保存护理和损坏状态；检测到用户换新行为时重置该对象的护理/损坏基线。退出期间不累计惩罚。先由用户确认“重算”的含义 |
| D02 | C 是全局还是逐文件，文件数量、已损坏文件是否让清洁度永远无法达到 100% | 全局 C 用于档位，各文件保存自身清洁状态；明确有效对象和损坏对象处理，避免不可逆低分循环。100% 使用可达成的干净判据，避免浮点误差卡住奖励 |
| D03 | 三天是累计在线 72 小时还是跨三个自然日；退出暂停还是清零；触发后是否重复 | 低于 15% 的连续有效运行累计时间，退出/休眠暂停，回升到 15% 清零；每个连续低值区间最多损坏一个。以上均需确认 |
| D04 | 低于 35% 没收入，没钱买护理用品可能无法翻身；批量设备是否过强 | 保留免费但较慢的基础护理，设备购买速度与便利；明确双击打开不自动全洗净 |
| D05 | 每日金币结算点、离线收入、湿度品相函数、幼菇价格、铲子耐久/消耗未定 | 先模拟正常照料、少量养菇、长期低清洁、频繁重启和大量文件五类行为，再定 B 与商品价格。不可把免离线惩罚推导成已批准的离线金币规则 |
| D06 | 重播提示、快捷键动作、工具切换、主窗口关闭与退出 | 短提示解释快进，入口集中到管理窗口；托盘能找回窗口。是否跳过及默认热键等待交互流程确认 |

## 辅助经济的后续检查（非当前主线）

固定已确认的档位倍率，扫描基础每日金币 B、设备价格、耗材成本与蘑菇价格。记账关系为“净收入 = 按所选结算规则计算的基础金币 × 档位倍率 + 蘑菇收入 − 护理开销”，不是已批准的结算算法。

100% 与普通干净状态的倍率差为 10 / 1.5 ≈ 6.67。此差值不是要求建立经营平衡系统的理由。辅助功能落地时只需检查价格是否妨碍用户体验工具、结算是否重复、低清洁是否造成操作死路；不以维持养菇吸引力、控制升级周期或防止玩家收益最优作为产品目标，不增加复杂货币回收系统。当前尚未运行模拟，也未确定价格。

## 后续工程边界（未实施）

拆分原生桌面读取、文件状态演进、经济结算、视觉呈现与管理窗口。状态层区分含水量、霉渍、清洁度、损坏、护理记录和惩罚时间；渲染层不得反过来修改真实文件或计算收益。新字段需旧存档迁移设计，当前不修改保存格式或 API。

原生坐标读取失败应明确提示并保留桌面可用性，不能静默使用巨大图标或重排网格。多屏、DPI、显示缩放、图标大小切换、文件新增/删除/重命名以及系统虚拟图标均需纳入验收。

建议顺序：原生尺寸下的连续发霉样片 → 桌面融合与轻量交互评审 → 发霉过程实现及原生 UAT → 按实际体验补齐必要辅助功能。样片重点看湿润、霉点扩散、幼芽伸柄展伞、根部附着、轻微摇摆、55% 遮挡和 3–5 秒快进是否成立；不先制作经济模型。D01 在涉及真实重启状态实现时处理，不阻塞美术样片。开发仍暂停，当前仅修正文档。
