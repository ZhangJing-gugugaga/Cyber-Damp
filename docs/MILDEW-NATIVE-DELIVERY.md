## 遮挡口径（实现前冻结）

分母：未变形原图显示尺寸下 alpha≥128 的有效像素集合 A。分子：所有霉斑、腐化和菇体在 A 内的覆盖像素并集，不重复计多层。各效果在独立测量 pass 输出几何覆盖 mask（自身层 alpha≥0.05 计入；透明像素不计），重采样到实际物理像素后计算 |A∩union(mask)|/|A|≤0.55。水光单列报告，不以水光颜色变化冒充霉层遮挡。接触阴影同时列入保守覆盖并集。

固定种子逐阶段、不同图标 alpha 轮廓、严重状态和摆动极值均测；保留原图、逐层 mask、并集和叠加图，并在正常尺寸人工复核邻近图标与标签。RGB 差异仅辅助查错，不作为55%达标依据。浅/深/复杂壁纸连续录屏和用户最终观察不可省略。

## 性能方案与预算（v1，实现前冻结）

本预算是验收门槛，不是实测结果。冻结后不得根据产品测试结果上调。

- 场景：启动4秒演出（5次完整启动，提示/加载另记）、静止桌面5分钟（完成加载后预热60秒）、自然演进连续30分钟（不篡改时钟）；暂停/隐藏另测60秒。30分钟使用当前完整真实图标数量，记录显示器/DPI、包哈希、开窗遮挡、功耗模式和用户活动。
- 进程：Windows Get-Process / Win32_Process，每1秒按指定产品根PID及后代追踪；CPU为进程累计CPU秒差 / 实际墙钟间隔 / 逻辑处理器数 ×100，汇总全进程。内存同时记录 WorkingSet64 与 PrivateMemorySize64，不能仅主进程。
- 帧：渲染首帧起记录 performance.now() 原始帧间隔，按每1秒窗口汇总；暂停明确标注不以零FPS判失败。采样不得改变状态、时间或输入。
- 静止：全进程CPU均值≤5%，p95≤10%；演出CPU均值≤15%，p95≤25%；30分钟CPU均值≤8%，p95≤15%。以本机8逻辑核归一化。
- 内存：全进程私有内存峰值≤800MiB；30分钟排除前5分钟预热，末5分钟中位数相对第5–10分钟中位数增长≤50MiB，分钟中位数线性斜率≤1MiB/分钟。两个增长条件同时满足；新增窗口与资产需记录。
- 帧间隔：可见演出及自然运行p95≤33.4ms、p99≤50ms；不得连续5秒低于30FPS；单次停顿>250ms需要调查，不能默默丢弃。静止若主动降帧必须另报策略且不能用于规避演出/交互门槛。
- 隐藏/暂停：CPU均值≤1%；演进时间不增长。
- 原始数据：`logs/mildew-native/performance/<run>/` 下 metadata.json、processes.jsonl、frames.jsonl、summary.json；丢样、进程退出、休眠、工具异常均写事件；缺帧数据或不足30分钟标未测，不从短录屏推断性能合格。
- 实现前已完成旧版约5分钟参考采样（见下节）。预算未调整，现已进入实现，禁止事后放宽。

- 旧版原生截图：`logs/native-uat/mildew-old-product-before-action-1.png`，已人工查看，确认图标放大、网格重排、角部发黑和旧成熟菇。只记录旧版差距。
- `baseline/process-sample/processes.jsonl`：266个有效样本，末采样299.43秒，平均CPU10.861%、p95 11.233%、峰值私有内存514.45MiB。采样间隔含CIM开销，实际约1.1秒，原始间隔逐条保留。该轮含遮挡/用户活动且不足30分钟，不是最终合规性能场景；不能宣称静止或长期性能通过。

- 新增 `win32-shell-view.ts`、`win32-shell-rects.ts` 与 `shell-layout-worker.ts` / `shell-layout.ts`：COM读真实标识与位置，LVM读图标/标签矩形，独立worker有5秒失败返回；尚未接入生产扫描和绘制。接口顺序核对 Microsoft WinSDK ExDisp.h、ShObjIdl_core.h；[GetViewModeAndIconSize](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifolderview2-getviewmodeandiconsize) 提供当前图标尺寸。
- `layout/query-check.json`：连续11次真实Shell读取一致，后10次约126–154ms。只证明当前环境读取稳定，不证明其他DPI、多屏或失败恢复。
- `npm run typecheck`、`npm run build:main` 通过；冻结的17个样片文件重新验哈希全部一致。未运行新生产视觉验收。
