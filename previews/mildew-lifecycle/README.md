# 一枚真实图标的回南天动态样片

打开 `index.html` 即可观看，或运行 `node previews/mildew-lifecycle/serve.cjs` 后访问 http://127.0.0.1:4179。

- 图标来自本机桌面 work 文件夹的 Windows Shell 原画，仅读取图标，不读取文件内容、不修改桌面。
- 提取源为 256px；注册表桌面 IconSize 为 48，主屏缩放 125%。左侧按 48 CSS px 图像框显示，右侧为放大观察。尚未与 Explorer 实际屏幕边界逐像素比对，浏览器缩放也会影响物理大小，因此称“桌面尺寸参考”，不宣称通过原生尺寸验收。
- 24 秒完整观察：受潮→霉点→霉斑→幼芽→展伞→干燥留痕→清洗恢复。最后的清洗是演示操作，不代表未来产品会自动清洗或自动移除蘑菇。
- 4 秒启动快进：只到成熟，结束停止。支持暂停、时间轴、半速和三种背景。
- 原生图标不重绘；霉变与蘑菇使用可连续形变的 Canvas 路径绘制，未调用生图服务。此为运动/附着关系样片，不是最终全量美术资产。
- `check-preview.cjs` 使用隐藏 Electron 窗口检查阶段渲染、图像载入与 4 秒播放，输出 review 截图及检查记录。自动视觉变化比例仅作遮挡风险筛查，不替代用户视觉验收。
- 该预览不接入主程序、金币系统、存档或真实桌面交互，不代表原生 UAT 完成。

观察重点：左侧是否看得出变化；黑点是否像逐渐长出来；菇根是否贴合；展伞是否仍像贴图缩放；4 秒是否看得清。

2026-10-20 用户明确认可：“可以，我非常喜欢这个特效，就按照这个样片来”。本目录作为下一轮生产开发的视觉基准，后续实验另存，不覆盖已认可效果。此结论仅针对样片，原生产品集成仍待验收。
